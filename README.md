# DocuFirma

Firma electrónica avanzada (biométrica) con sello de tiempo cualificado RFC 3161 para autónomos y pymes.

- Producto y arquitectura: [`CLAUDE.md`](./CLAUDE.md)
- Plan y estado: [`docs/PLAN.md`](./docs/PLAN.md)
- Decisiones: [`docs/DECISIONS.md`](./docs/DECISIONS.md)

## Desarrollo local

```bash
pnpm install
cp .env.example .env.local   # rellena las variables
pnpm dev
```

La guía completa de despliegue desde cero se completa en la Fase 8.
